# Project Constitution: Code Provenance

## Project Identity
- **Name**: Code Provenance
- **Purpose**: A code fingerprinting engine that detects AI-generated vs human-written code, identifies code theft, license violations, and traces code lineage across the open-source ecosystem.
- **Tagline**: "Every line of code has a story. We tell it."

## Core Principles
1. **Accuracy-first**: Zero tolerance for false positives on provenance claims
2. **Language-agnostic**: Analyze code in any programming language
3. **Privacy-respecting**: Never uploads code to external services
4. **Forensic-grade**: Results defensible in legal proceedings
5. **Open-source**: Community-driven, MIT licensed
